Quake for the PlayStation 2 - release 1.0.0
===============================================

An unofficial, fan-made port of id Software's Quake to the Sony
PlayStation 2, based on QuakeSpasm and built entirely with the free
PS2DEV SDK.

  Project home:  https://github.com/glampert/quake-ps2
  Source code:   https://github.com/glampert/quake-ps2/tree/28c6c1c062eff6b2b85edca9d986f9a0e4010182
                 (the exact commit these ELFs were built from)

This package contains only the program. It does not contain the Quake
game data (id1/pak0.pak, and pak1.pak for the registered game), which is
not free software: use the shareware episode or your own copy of the
game. See the project page for how to set up the id1/ folder and run the
game on a console or in PCSX2.
